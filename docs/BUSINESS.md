# Business

Value proposition: one decision loop that turns forecasts into feeder-safe dispatches with a money/CO2 receipt. Not five demos — one VPP that pays.

SaaS tiers: Starter (per site, forecast + ledger), Fleet (per asset per month: EV/battery optimization), VPP/Utility (platform fee + % of verified savings, e.g. 15% of measured peak-cost reduction).

Adoption path: (1) commercial buildings + EV fleets (evening peak pain), (2) aggregators as VPP operators, (3) utilities/grid operators (black-start copilot, demand response).

Cross-border: region configs drive tariffs/currency/carbon. Launch Bangladesh/India/SE Asia (high evening peak, high carbon), then EU (day-ahead price, OPSD), then US PJM (LMP). No code change to add a region — one config entry.

Validation hypotheses & pilot KPIs: 8-15% energy-cost reduction, 5-12% peak reduction, forecast MAPE <10%, SoC-guarantee 100%, operator approval rate >80%.
