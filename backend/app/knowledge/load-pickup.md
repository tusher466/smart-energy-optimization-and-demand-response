# Load pickup procedure

Pick up load in small blocks (2-3 MW). After each block, wait for frequency to recover to 50.0 Hz.
Priority order: hospitals and critical services first, then feeders with high load factor.
Cold load pickup can be 2x normal: derate block sizes in the first hour.
If frequency dips below 48.8 Hz, shed the last block and hold. Never stack two blocks without a stability check.
Synchronize separate islands only at near-zero phase difference with synch-check relay supervision.
